# ✅ Task App

Organizador de tareas por áreas y proyectos, con calendario, prioridades y sincronización en la nube. Simple, oscuro y rápido.

**👉 Usala acá: [monster-javi.github.io/task-app](https://monster-javi.github.io/task-app/)**

---

## Qué hace

**🗂️ Áreas y proyectos**
- Separá trabajo, casa, estudio… y adentro, cada proyecto con sus tareas.
- Estados: por hacer, haciendo y hecho. Prioridad alta, media o baja.
- Favoritas, notas por tarea y arrastrar y soltar para reordenar.

**👀 Tres formas de verlas**
- **Lista**: todo agrupado por área y proyecto.
- **Por prioridad**: lo urgente primero.
- **Calendario**: con las fechas de vencimiento y los feriados de tu país.

**⚡ Carga rápida**
- Escribí varias tareas de una en texto libre y se reparten solas.

**🔔 Avisos**
- Te avisa de lo vencido y de lo que vence mañana.

**Y además**
- Sincronización en tiempo real entre la compu y el celular.
- Funciona en el celular.
- Se puede probar sin crear cuenta.

## Privacidad

- Cada usuario ve solo sus datos.
- **Cifrado de extremo a extremo** opcional, desde el candado de arriba: tus tareas se guardan cifradas y ni el servidor puede leerlas. La contraseña nunca sale de tu navegador; si la perdés, no hay forma de recuperar los datos.

## Cómo está hecha

- **React + Vite**, publicada en GitHub Pages.
- **Supabase** para el login, la base de datos y la sincronización.

Hermana de [Gastos App](https://github.com/monster-javi/gastos-app): comparten el diseño y la idea.
